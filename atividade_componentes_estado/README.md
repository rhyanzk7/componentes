# Atividade: Componentes e Estado

Projeto demonstrativo em Kotlin com Jetpack Compose.

## Componentes incluídos
- OutlinedTextField: recebe um nome e atualiza a saudação.
- Buttons: aumentam, diminuem e zeram um contador.
- Checkbox: alterna o estado de uma tarefa.
- Switch: liga e desliga as notificações.
- Slider: altera um nível de 0 a 100.

## Conceito de estado
Os valores são mantidos com `rememberSaveable` e `mutableStateOf`. Quando um valor muda, o Jetpack Compose recompõe a parte necessária da interface.

## Como usar
Substitua o conteúdo do arquivo `MainActivity.kt` do projeto Android pelo arquivo fornecido. Mantenha o `package` compatível com o pacote do seu projeto. Abra/sincronize o projeto no Android Studio e execute em um emulador ou aparelho Android.

Observação: este material é uma implementação demonstrativa baseada no título e no projeto inicial mostrado. Confira se a professora apresentou componentes específicos em aula antes de entregar.
